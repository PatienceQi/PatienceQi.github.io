Hybrid Precision Runtime

为推理服务自动调度混合精度策略，实现吞吐与精度的动态平衡。

问题

在企业 GPU 集群中同时运行多模型推理任务时，固定的混合精度配置无法兼顾所有场景：较激进的配置会导致数值不稳定，而保守配置又浪费吞吐。需要一个能够按算子、按批次动态选择精度的运行时，同时兼顾运维监控。

方法

设计三阶段流程：静态图分析 → 在线算子探测 → 反馈调优。利用 MindSpore 自定义算子钩子捕获精度敏感度，并将结果写入 Redis 供后续批次查询。

结果

模型 基线延迟 优化后延迟 精度下降
BERT-Base 68 ms 49 ms <0.1%
GPT-6B 142 ms 96 ms <0.2%

职责

  • 提出并实现混合精度调度算法，支持 MindSpore 和 TensorFlow。
  • 构建在线探测服务，将精度异常写入 Prometheus 以供告警。
  • 编写运维手册，帮助团队在 4 天内完成灰度上线。
